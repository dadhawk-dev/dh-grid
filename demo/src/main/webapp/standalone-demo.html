⚡ DhGrid Web Component Showcase <dh-grid-element>
What is this page & How to use it?
This page demonstrates the standalone W3C Web Component (<dh-grid-element>) running natively in HTML5. It requires no Java backend or server-side JSF container, proving that DhGrid can be embedded directly into pure HTML, React, Vue, or Angular applications.
Step 1: Keyboard Navigation
Use Arrow Keys to navigate cells. Press Tab to move right (wrapping rows), Enter to edit/save & move down, Escape to cancel.
Step 2: Inline Cell Editing
Double-click or press Enter on any cell to trigger inline editing. Press Enter or Tab to commit changes.
Step 3: Custom Web Component Editors
Double-click status cells or rating stars to launch custom elements (<status-selector>, <rating-editor>).
Step 4: Dynamic Matrix Expansion
Click + Add Row or + Add Col to dynamically add rows/columns to the matrix array in real-time.

💾 Download JS Script (dh-grid.js)
<!DOCTYPE html> <html> <head> <script src="resources/dadhawk/js/dh-grid.js"></script> </head> <body> <dh-grid-element id="myGrid" rows="5" cols="5" css-compatible="primethemes" readonly-cells='{"r1_c0": true, "r3": true}' cell-styles='{"r1_c3": "color:#4ade80;font-weight:700;", "c1": "color:#38bdf8;"}'></dh-grid-element> <script> const grid = document.getElementById('myGrid'); // PrimeFaces Theme Compatibility & Composite Tree Captions grid.setAttribute('css-compatible', 'primethemes'); grid.setAttribute('captions', JSON.stringify([ "Sales / H1 / Q1", "Sales / H1 / Q2", "Sales / H2 / Q3", "Sales / H2 / Q4", "Status" ])); grid.setAttribute('content', JSON.stringify([ ["Header", "Q1", "Q2", "Q3", "Status"], ["2026 Q1", "$120k", "$85k", "29.1%", "Completed"], ["2026 Q2", "$145k", "$92k", "36.5%", "Active"], ["2026 Q3", "$160k", "$98k", "38.7%", "Pending"], ["2026 Q4", "$210k", "$110k", "47.6%", "In Review"] ])); grid.setAttribute('components', JSON.stringify({ "r1_c4": "status-selector" })); // Cell ReadOnly Rules & Custom Cell Styling API grid.readOnlyCells = { "r1_c0": true, "r3": true }; grid.cellStyles = { "r1_c3": "background-color: rgba(34, 197, 94, 0.15); color: #4ade80; font-weight: 700;", "c1": "color: #38bdf8; font-weight: 600;" }; grid.addEventListener('cell-change', (e) => { console.log(e.detail.row, e.detail.col, e.detail.value); }); </script> </body> </html>
🅱️ Minimal Quick-Start Examples for JSF Developers (JSF View + Bean)
<!-- page.xhtml --> <html xmlns="http://www.w3.org/1999/xhtml" xmlns:h="jakarta.faces.html" xmlns:f="jakarta.faces.core" xmlns:dh="http://dadhawk.com/faces"> <h:head><title>JSF Grid</title></h:head> <h:body> <h:form id="gridForm"> <dh:dhGrid id="myGrid" rowCount="#{gridBean.rowCount}" colCount="#{gridBean.colCount}" cssCompatible="primethemes" content="#{gridBean.content}" captions="#{gridBean.captions}" componentMap="#{gridBean.componentMap}" readOnlyCells="#{gridBean.readOnlyCells}" cellStyles="#{gridBean.cellStyles}" /> <!-- Save Grid to Backend Managed Bean --> <h:commandButton value="💾 Save Grid to Backend" action="#{gridBean.saveGrid()}"> <f:ajax execute="@form" render="saveStatus" /> </h:commandButton> <h:outputText id="saveStatus" value="#{gridBean.lastSaveStatus}" /> </h:form> </h:body> </html> // Java CDI Backing Bean (@Named @SessionScoped): @Named("gridBean") @SessionScoped public class GridBean implements Serializable { private String[][] content; private String lastSaveStatus; // Backend Action Method invoked on form save button public String saveGrid() { int r = (content != null) ? content.length : 0; int c = (r > 0 && content[0] != null) ? content[0].length : 0; this.lastSaveStatus = "Saved " + r + "x" + c + " matrix to GridBean!"; return null; } public String[][] getContent() { return content; } public void setContent(String[][] content) { this.content = content; } public String getLastSaveStatus() { return lastSaveStatus; } }

☕ Jakarta Faces 4.0 (JSF) Integration Guide
ℹ️ Note: GitHub Pages serves static HTML assets. To run the full Jakarta Faces 4.0 server-side application with Java CDI managed beans (GridBean.java) and JSF EL expressions (#{gridBean.content}), follow these 3 quick steps locally:
1️⃣ Add Maven Dependency (pom.xml)
<dependency>
    <groupId>com.dadhawk.faces</groupId>
    <artifactId>dhgrid-component</artifactId>
    <version>1.0.0-RC2</version>
</dependency>
2️⃣ Embed Taglib in JSF Facelets View (index.xhtml)
<!DOCTYPE html>
<html xmlns="http://www.w3.org/1999/xhtml"
      xmlns:h="jakarta.faces.html"
      xmlns:dh="http://dadhawk.com/faces">
  <h:body>
      <h:form id="gridForm">
          <dh:dhGrid id="myGrid"
                     rowCount="#{gridBean.rowCount}"
                     colCount="#{gridBean.colCount}"
                     content="#{gridBean.content}"
                     captions="#{gridBean.captions}"
                     componentMap="#{gridBean.componentMap}" />
      </h:form>
  </h:body>
</html>
3️⃣ Run Local Jakarta Faces 4.0 Showcase Server
git clone https://github.com/dadhawk-dev/dh-grid.git
cd dh-grid
./run-app.sh
App endpoint: http://localhost:8085/index.xhtml
