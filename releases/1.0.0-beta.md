## 🌟 Overview

`v1.0.0-beta` introduces **Fine-Grained Cell ReadOnly Control** and **Dynamic Cell Styling Strategies** (`cellStyles` / `readOnlyCells`) for both Jakarta Faces 4.0 (`<dh:dhGrid>`) and W3C Web Component (`<dh-grid-element>`).

---

## ✨ What's New in v1.0.0-beta

### 1. 🔒 Cell ReadOnly Control (`readOnly`, `readOnlyCells`)
- **Global ReadOnly Mode**: Set `readOnly="true"` (`readonly` attribute) to lock all data cells grid-wide.
- **Per-Cell & Per-Column Rule Maps**: Targeted editability rules via JSON string or Map:
  - `readOnlyCells='{"r1_c0": true, "c0": true}'`
- **Visual Feedback & Animation**: Read-only cells feature distinct non-editable cursor styles and subtle lock-shake animation on double-click attempt.

### 2. 🎨 Dynamic Cell Styling Strategy (`cellStyles`)
- **Per-Cell, Column, or Row Styling**: Apply custom background colors, text colors, font weights, and font sizes directly:
  - `cellStyles='{"r1_c3": "background-color: rgba(34, 197, 94, 0.15); color: #4ade80; font-weight: 700;"}'`
- **Shorthand Object & CSS Rule String Support**: Supports both inline CSS strings and shorthand JSON objects (`{ "bg": "#1e3a8a", "color": "#60a5fa" }`).

### 3. ☕ Jakarta Faces 4.0 Component Expansion
- Added `readOnly`, `readOnlyCells`, and `cellStyles` properties to `<dh:dhGrid>` Facelets tag library with full EL expression binding support (`readOnlyCells="#{gridBean.readOnlyCells}"`, `cellStyles="#{gridBean.cellStyles}"`).
