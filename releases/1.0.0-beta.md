## 🌟 Overview

**Dadhawk DhGrid Component v1.0.0-beta** fixes JSF form submission model updates when saving grid data (`saveData` / `saveGrid`) to backing beans (`GridBean`), adds `blur` / focusout auto-commit event listeners for inline custom editors, and enhances 2D JSON matrix decoding.

---

## 🐛 Bug Fixes & Enhancements

### 1. 💾 JSF `saveData` / `saveGrid` Backing Bean Model Sync Fix
- **Evaluated `content` ValueExpression**: `DhGridComponent.updateModel()` now evaluates `getValueExpression("content")` (falling back to `"value"`) during JSF Process Validations / Update Model phase. This ensures that form actions (`<h:commandButton action="#{gridBean.saveGrid}">`) properly set the updated matrix back to the backing bean property (`gridBean.setContent(...)`).
- **Enhanced JSON Matrix Parser**: `DhGridComponent.parseJsonMatrix()` was upgraded to handle both quoted strings and unquoted values (numeric/boolean tokens) sent by the web component.
- **Resilient Container Decoding**: Added fallback suffix matching for `:componentId_input` request parameters in `decode()`, supporting complex JSF container component hierarchies (`<p:tabView>`, `<p:outputPanel>`, `<h:form>`).

### 2. ⚡ Editor `blur` & `focusout` Auto-Commit
- **Auto-Commit on Focus Loss / Save Click**: Added `blur` event listeners to all inline custom editors (`<dh-editor-input-text>`, `<dh-editor-input-number>`, `<dh-editor-input-money>`) and overlay inputs. When a user clicks outside or clicks a toolbar Save button without pressing Enter or Tab, cell changes are immediately committed and synced to the hidden input before form submission.
- **Single Commit Guard**: Added `isCommitted` flag to `commitAndNavigate()` to prevent duplicate commits.
