## 🌟 Overview

`v1.0.0-RC1` (Release Candidate 1) introduces **Backend Form Save & Model Synchronization** for Jakarta Faces 4.0 (`<dh:dhGrid>`) and **Global JavaScript State Synchronization (`window.dhGridData`)** for client-side environments.

Component data modified by users client-side is now automatically synchronized to Java CDI Managed Beans (`GridBean.java`) during JSF lifecycle form submissions and AJAX action requests.

---

## ✨ What's New in v1.0.0-RC1

### 1. 💾 Jakarta Faces 4.0 Backend Form Save & Model Binding
- **Extends `UIInput`**: `DhGridComponent` now inherits from `jakarta.faces.component.UIInput`, enabling native JSF form decode, validation, and model update phases.
- **Form Decode (`decode`)**: Automatically extracts the submitted JSON 2D matrix from hidden request parameter (`clientId_input`).
- **Zero-Dependency JSON Parser (`parseJsonMatrix`)**: Built-in robust string parser parses submitted JSON arrays into Java `String[][]` arrays without requiring external dependencies (like Jackson or Gson).
- **Model Update (`updateModel`)**: Automatically updates backing bean properties bound via `content="#{gridBean.content}"` during the `Update Model Values` JSF lifecycle phase.
- **Backend Save Action**: Supports standard JSF action methods such as `action="#{gridBean.saveGrid}"` on `<h:commandButton>`.

### 2. 🌐 Global Client-Side JavaScript State (`window.dhGridData`)
- Automatically populates and updates `window.dhGridData[gridId]` and `window.dhGridDataContent` whenever grid data changes (editing cells, adding rows, expanding columns, or initial render).
- Automatically updates hidden form input element (`#clientId_input`) in real-time.

### 3. 🎯 Interactive Showcase Enhancements
- Updated demo application (`index.xhtml`) with a dedicated **"💾 Save Grid to Backend"** button executing `#{gridBean.saveGrid}` via `<f:ajax execute="@form" render=":gridForm:saveStatusMsg :statsPanel" />`.
- Live feedback status message confirming server-side matrix save with dimensions and timestamp.
