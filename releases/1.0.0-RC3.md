## 🌟 Overview

`v1.0.0-RC3` (Release Candidate 3) introduces overall grid **`readOnly` / `readonly` property support** across the entire stack—including Jakarta Faces 4.0 (`DhGridComponent`), W3C Web Component (`<dh-grid-element>`), Taglib (`dadhawk.taglib.xml`), backing bean (`GridBean`), and interactive live showcases.

---

## ✨ What's New in v1.0.0-RC3

### 1. 🔒 Overall Grid ReadOnly Property & Property Aliases
- **JS & Web Component**: `DhGridElement` supports both camelCase `readOnly` and lowercase `readonly` property getters/setters (`grid.readOnly`, `grid.readonly`) and host attributes (`readOnly="true"`, `readonly="true"`).
- **Jakarta Faces 4.0 Component**: `DhGridComponent` supports `readOnly` and `readonly` properties in EL expressions (`readOnly="#{gridBean.readOnly}"`) and exposes getter/setter methods (`isReadOnly()`, `getReadOnly()`, `isReadonly()`, `getReadonly()`, `setReadOnly()`, `setReadonly()`).
- **Facelets Taglib**: Declared `readonly` attribute alias in `dadhawk.taglib.xml`.
- **Lock-Shake Feedback & Visual Cue**: Setting grid-wide `readOnly` renders all matrix data cells with read-only styling (`grid-cell-readonly`) and triggers lock-shake animation feedback when edit attempts (`Enter`, double click) occur.

### 2. ⚡ Demo Application & Version Synchronization
- **Backing Bean Integration**: Added `readOnly` state and `toggleReadOnly()` action method in `GridBean.java`.
- **Interactive UI Toggle**: Added "🔒 Lock Grid (readOnly=true)" / "🔓 Unlock Grid" button in `index.xhtml` showcase toolbar.
- **Synchronized Version Tags**: Updated library POM (`pom.xml`), demo POM (`demo/pom.xml`), build script (`run-app.sh`), documentation, download packages, and showcase web pages to version `1.0.0-RC3`.
