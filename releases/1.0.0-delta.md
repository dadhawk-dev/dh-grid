## 🌟 Overview

`v1.0.0-delta` introduces a **Keyboard Navigation & Focus Management System** for both Jakarta Faces 4.0 (`<dh:dhGrid>`) and W3C Web Component (`<dh-grid-element>`). Users can seamlessly navigate matrix cells and edit content using intuitive keyboard shortcuts (`Arrow Keys`, `Tab`, `Shift+Tab`, `Enter`, and `Escape`).

---

## ✨ What's New in v1.0.0-delta

### 1. ⌨️ Keyboard Navigation Shortcuts
- **Arrow Keys (`Up` / `Down` / `Left` / `Right`)**: Move cell focus seamlessly across matrix rows and columns without triggering page scroll.
- **`Tab` Key**:
  - **Non-editing mode**: Focuses the next cell to the right (wrapping to the first cell of the next row at the end of a line).
  - **Editing mode**: Commits the active cell edit, closes the editor, and moves focus to the right cell.
- **`Shift + Tab` Key**:
  - Moves focus backward to the left cell (wrapping to the last cell of the previous row at the start of a line).
- **`Enter` Key**:
  - **Non-editing mode**: Launches the cell editor for the focused cell.
  - **Editing mode**: Commits the current edit, closes the editor, and moves focus down to the cell below.
- **`Escape` Key**:
  - Cancels the active cell edit without saving changes and returns focus to the target cell.

### 2. 🎯 Active Cell Focus Ring & Accessibility (`tabindex="0"`)
- Every data cell supports native keyboard accessibility (`tabindex="0"`).
- Visually demarcated active focus ring (`.grid-cell-focused`) with automatic `scrollIntoView` for large matrix scrolling.

### 3. 🎨 PrimeFaces Theme Compatibility (`css-compatible="primethemes"`)
- Set `css-compatible="primethemes"` on `<dh-grid-element>` or `cssCompatible="primethemes"` on `<dh:dhGrid>` to bind Shadow DOM table styling (`--dh-table-bg`, `--dh-cell-color`, `--dh-border-color`) to active PrimeFaces / PrimeVue CSS variables (`--surface-a`, `--surface-b`, `--surface-border`, `--text-color`, `--primary-color`).
- Automatically adapts to user profile theme selections such as `saga-blue`, `arya`, `vela`, `luna-amber`, etc.
