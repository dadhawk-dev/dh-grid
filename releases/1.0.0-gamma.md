## 🌟 Overview

`v1.0.0-gamma` introduces **PrimeFaces Theme Compatibility** (`css-compatible="primethemes"`) for both Jakarta Faces 4.0 (`<dh:dhGrid>`) and W3C Web Component (`<dh-grid-element>`). This enables seamless visual integration with standard PrimeFaces themes (e.g. `saga-blue`, `arya`, `vela`, `luna-amber`, `nova`, `primeflex`) by binding Shadow DOM CSS variables to host PrimeThemes custom properties.

---

## ✨ What's New in v1.0.0-gamma

### 1. 🎨 PrimeFaces Theme CSS Compatibility (`css-compatible="primethemes"`)
- **Shadow DOM Style Mapping**: Internal custom properties (`--dh-table-bg`, `--dh-header-bg`, `--dh-border-color`, `--dh-cell-color`, `--dh-hover-bg`, `--dh-focus-ring`, `--dh-readonly-bg`) automatically resolve to host PrimeThemes variables (`--surface-a`, `--surface-b`, `--surface-c`, `--surface-border`, `--text-color`, `--text-color-secondary`, `--primary-color`, `--focus-ring-color`).
- **Dynamic Attribute Observation**: Add `css-compatible="primethemes"` on `<dh-grid-element>` or `cssCompatible="primethemes"` on `<dh:dhGrid>`. Any theme switch in PrimeFaces instantly updates the DhGrid rendering without Shadow DOM style leaks or manual CSS overrides.

### 2. ☕ Jakarta Faces 4.0 Tag & Component Attribute Expansion
- Added `cssCompatible` property to `DhGridComponent.java` and `dadhawk.taglib.xml`.
- Fully bindable with Facelets EL expressions: `<dh:dhGrid cssCompatible="#{gridBean.cssCompatible}" ... />`.

### 3. 🚀 Interactive Showcase & Theme Switcher
- Added live **PrimeThemes Theme Switcher** bar in the showcase demo allowing developers to test DhGrid against `Saga Blue`, `Arya Dark`, `Vela Blue`, and `Luna Amber` themes with a single click.
