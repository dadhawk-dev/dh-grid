## 🌟 Overview

**Dadhawk DhGrid Component v1.0.0-gamma** resolves the row indexing issue when explicit `captions` are provided on `<dh-grid-element>`. Previously, `render()` hardcoded `startRow = 1`, causing row 0 of `content` (e.g. `["Quarter", "Revenue ($)", "Expenses ($)", ... ]`) to be skipped in `tbody`. With `v1.0.0-gamma`, `hasExplicitCaptions()` dynamically sets `startRow = 0` when explicit captions are passed, rendering all content rows in full.

---

## 🐛 Bug Fixes & Enhancements

### 1. 📊 Explicit Captions & Dynamic Row Start Fix (`startRow` & `minRow`)
- **Dynamic Row Indexing**: Added `hasExplicitCaptions()` check to `DhGridElement` in `dh-grid.js`. When explicit `captions` attribute is set, `startRow` and `minRow` dynamically start at `0` so row index 0 of `content` is properly rendered in `tbody`.
- **Keyboard Navigation & Focus Bounds**: `focusCell()`, `getNextTabPosition()`, and keyboard handlers now start at `minRow = 0` when explicit captions exist, preserving full cell focus and key navigation for row 0.
- **Backward Compatibility**: When `captions` is omitted, `getCaptions()` continues to fall back to `data[0]` for headers and starts `tbody` at `startRow = 1`.
