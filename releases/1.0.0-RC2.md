## 🌟 Overview

`v1.0.0-RC2` (Release Candidate 2) addresses GitHub Pages Maven Repository artifact resolution, updating `maven-metadata.xml` and metadata indexing so external projects (such as `fms-web`) can resolve `com.dadhawk.faces:dhgrid-component:1.0.0-RC2` directly from `https://dadhawk-dev.github.io/dh-grid/maven-repo/`.

## ✨ What's New in v1.0.0-RC2

### 1. 📦 GitHub Pages Maven Repository Fixes & Metadata Indexing
- **Fixed Artifact Resolution**: Updated repository `maven-metadata.xml` with complete version indices (`1.0.0-alpha`, `1.0.0-beta`, `1.0.0-gamma`, `1.0.0-delta`, `1.0.0-RC1`, `1.0.0-RC2`, `1.0.0`) and correct release/latest tags (`1.0.0-RC2`).
- **Clean Remote Repositories**: Removed local tracking files (`_remote.repositories`) from public repo directories to prevent resolution blocking in external Maven environments.
- **Checksums**: Updated MD5 and SHA1 checksums for repository metadata.

### 2. ⚡ Release Candidate Versioning Sync
- Synchronized library POM (`pom.xml`), demo module (`demo/pom.xml`), build script (`run-app.sh`), documentation, download packages, and showcase web pages to version `1.0.0-RC2`.
