## 🌟 Overview

**Dadhawk DhGrid Component v1.0.1-beta** includes fixes for dynamic grid dimensions and locale-aware number parsing for inputs (`input-number` & `input-money`).

---

## 🐛 Bug Fixes & Improvements

### 1. 📐 Dynamic Matrix Dimension Calculation
- Fixed `get rows()` and `get cols()` getters in `dh-grid.js` to respect explicit attributes (`attrRows` / `attrCols`) and data dimensions instead of forcing min 5.

### 2. 🌍 Locale-Aware Number & Currency Parser
- Fixed `parseRawNumber(val, loc)` to correctly handle thousand separators (`.` vs `,`) based on `locale` (e.g. `tr-TR` vs `en-US`).
- Prevents truncation on numbers formatted with multiple thousand separators (e.g. `123.123.123` $\rightarrow$ `123123123`).
