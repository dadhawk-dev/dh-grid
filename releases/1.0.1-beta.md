## 🌟 Overview

**Dadhawk DhGrid Component v1.0.1-beta** includes critical fixes for editor blur focusout event listeners, cell synchronization before form submission, and resilient JSF parameter decoding.

---

## 🐛 Bug Fixes & Enhancements

### 1. ⚡ Editor `blur` & `focusout` Event Listener Commit
- **Auto-Commit on Focus Loss / Save Click**: Added `blur` event listeners to all inline custom editors (`<dh-editor-input-text>`, `<dh-editor-input-number>`, `<dh-editor-input-money>`) and overlay inputs. When a user clicks outside or clicks a toolbar Save button without pressing Enter or Tab, cell changes are immediately committed and synced to the hidden input before form submission.
- **Single Commit Guard**: Added `isCommitted` flag to `commitAndNavigate()` to prevent double-commit on keyboard navigation and focus changes.

### 2. 🔍 Resilient JSF Container Parameter Decoding
- **Suffix Search in `decode()`**: `DhGridComponent.decode()` now includes fallback suffix matching for `:componentId_input` request parameters, supporting complex JSF container component hierarchies (e.g. `<p:tabView>`, `<p:outputPanel>`, `<h:form>`).
