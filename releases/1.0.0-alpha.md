## 🌟 Overview

**Dadhawk DhGrid Component v1.0.0-alpha** is the initial alpha release of a high-performance, feature-complete dual-mode data grid library designed for **Jakarta EE / Jakarta Faces 4.0 (JSF)** applications and **standalone W3C Web Components (`<dh-grid-element>`)**.

DhGrid bridges traditional enterprise Java web applications with modern client-side Web Component standards, featuring parent-child composite tree headers, intelligent input editors, locale-aware number and currency formatting, dynamic styling, keyboard navigation, fine-grained read-only control, PrimeFaces theme compatibility, and seamless backend JSF form synchronization.

---

## ✨ Features & Major Capabilities

### 1. 🏗️ Dual-Mode Architecture & Framework Agnostic
- **Jakarta Faces 4.0 (JSF) Component**: Drop-in `<dh:dhGrid>` taglib component supporting full Facelets EL expression binding for matrix data, tree headers, component maps, read-only rules, and styling strategies.
- **W3C Native Web Component**: High-performance `<dh-grid-element>` encapsulated inside Shadow DOM running cleanly in Vanilla JS, HTML5, React, Vue, or Angular with zero external framework dependencies.

### 2. 🌳 Composite Parent-Child Tree Headers
- Multi-level hierarchical column headers constructed using path notation (`"Sales / H1 / Q1"`, `"Sales / H1 / Q2"`), 2D arrays, or nested tree objects.
- Automatic matrix calculation for complex multi-row `colspan` and `rowspan` table header layouts.

### 3. 🤖 Intelligent Editors & Component Map Integration
- **Built-in Intelligent Editors**:
  - `"input-text"`: High-contrast, clean inline text overlay editor.
  - `"input-number"`: Numeric editor with stepper controls (`▲`/`▼`), arrow key navigation, and automatic decimal parsing.
  - `"input-money"`: Currency editor with real-time numeric entry and automatic locale currency formatting.
- **Custom Web Component Editors**: Seamless cell binding to custom interactive widgets (`<status-selector>`, `<rating-editor>`, `<priority-badge-editor>`).
- Reactive event streams (`cell-change`) emitting updated cell coordinates, old values, and new values.

### 4. 🌐 Locale-Aware Number & Currency Formatting (`locale`)
- Built-in `locale` attribute for Jakarta Faces `<dh:dhGrid locale="en-US">` and Web Component `<dh-grid-element locale="...">`.
- Native integration with JavaScript `Intl.NumberFormat` to format raw numbers and money based on target country locales (e.g. `en-US`, `tr-TR`, `de-DE`).

### 5. 📐 Dynamic Matrix Dimension Calculation & Parsing
- Dynamic `rows` and `cols` calculation respecting explicit component attributes (`rows` / `cols`) and actual matrix dimensions.
- Robust parsing for numbers with dynamic thousand separators and decimal places across locales.
