## 🌟 Overview

`v1.0.0-alpha` is the initial open-source release of **DhGrid**, a high-performance dual-mode UI grid component for Java Jakarta EE / Faces 4.0 applications and standalone HTML5 Web Components.

---

## ✨ Features & Highlights

### 1. Dual-Mode UI Architecture
- **Jakarta Faces 4.0 Component**: Drop-in `<dh:dhGrid>` taglib component supporting EL expression binding for rows, columns, matrix content, and web component maps.
- **W3C Web Component**: Native `<dh-grid-element>` encapsulated inside Shadow DOM running cleanly in Vanilla JS, HTML5, React, Vue, or Angular without external framework dependencies.

### 2. 🌳 Composite Parent-Child Tree Captions
- Multi-level hierarchical column headers using intuitive path notation (`"Sales / H1 / Q1"`, `"Sales / H1 / Q2"`), 2D arrays, or nested tree objects.
- Automatic `colspan` and `rowspan` matrix calculation for complex table headers.

### 3. Custom Web Component Editors
- Seamless cell binding to custom interactive widgets (`<status-selector>`, `<rating-editor>`, `<priority-badge-editor>`).
- Floating overlay editor with automatic reactive event streams (`cell-change`).

### 4. Interactive Live Demo Preview Modal
- Embedded `▶ RUN Live Example` preview modal directly within standalone web showcases and documentation.
