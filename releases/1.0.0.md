## 🌟 Overview

`v1.0.0` is the official stable release of **Dadhawk DhGrid Component**, a high-performance data grid library engineered for both **Jakarta EE / Jakarta Faces 4.0 (JSF)** and **W3C Web Components (`<dh-grid-element>`)**.

---

## ✨ What's New in v1.0.0

### 1. 🌐 Locale-Aware Number & Currency Formatting (`locale`)
- Added `locale` attribute to Jakarta Faces `<dh:dhGrid locale="en-US">` and Web Component `<dh-grid-element locale="...">`.
- Native integration with JavaScript `Intl.NumberFormat` to format raw numeric and currency values according to country locales (e.g. `en-US` `$120,000.00`, `tr-TR` `₺120.000,00`, `de-DE` `120.000,00 €`, `ja-JP` `￥120,000`).

### 2. 🤖 Intelligent Input Editors (`input-number`, `input-text`, `input-money`)
- **`"input-text"`**: High-contrast, clean overlay text editor.
- **`"input-number"`**: Numeric editor with stepper controls (`▲`/`▼`), arrow key navigation, and automatic decimal/locale parsing.
- **`"input-money"`**: Currency editor with real-time numeric entry and automatic currency symbol placement.

### 3. 🔒 Overall Grid `readOnly` Matrix Lock API
- Full `readOnly` / `readonly` grid locking across Java component (`DhGridComponent`), Web Component (`<dh-grid-element>`), Taglib (`dadhawk.taglib.xml`), and CDI backing bean (`GridBean`).
- Visual lock-shake feedback animation on locked cell double-click.

### 4. 📄 JSF 2-Card Documentation & Code Copy
- Dedicated 2-card layout showcasing Facelets View (`page.xhtml`) and CDI Backing Bean (`GridBean.java`) with backend persistence integration (`saveData()`).
