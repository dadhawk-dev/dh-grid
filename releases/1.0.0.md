## 🌟 Overview

**Dadhawk DhGrid Component v1.0.0** is the official stable release of a high-performance, feature-complete dual-mode data grid library designed for **Jakarta EE / Jakarta Faces 4.0 (JSF)** applications and **standalone W3C Web Components (`<dh-grid-element>`)**.

DhGrid bridges traditional enterprise Java web applications with modern client-side Web Component standards, featuring parent-child composite tree headers, intelligent input editors, locale-aware formatting, dynamic styling, keyboard navigation, fine-grained read-only control, PrimeFaces theme compatibility, and seamless backend JSF form synchronization.

---

## ✨ Features & Major Capabilities

### 1. 🏗️ Dual-Mode Architecture & Framework Agnostic
- **Jakarta Faces 4.0 (JSF) Component**: Drop-in `<dh:dhGrid>` taglib component supporting full Facelets EL expression binding for matrix data, tree headers, component maps, read-only rules, and styling strategies.
- **W3C Native Web Component**: High-performance `<dh-grid-element>` encapsulated inside Shadow DOM running cleanly in Vanilla JS, HTML5, React, Vue, or Angular with zero external framework dependencies.

### 2. 🌳 Composite Parent-Child Tree Headers
- Multi-level hierarchical column headers constructed using path notation (`"Sales / H1 / Q1"`, `"Sales / H1 / Q2"`), 2D arrays, or nested tree objects.
- Automatic matrix calculation for complex multi-row `colspan` and `rowspan` table header layouts.

### 3. 🤖 Intelligent Editors & Component Map Integration
- **Built-in Intelligent Editors**:
  - `"input-text"`: High-contrast, clean inline text overlay editor.
  - `"input-number"`: Numeric editor with stepper controls (`▲`/`▼`), arrow key navigation, and automatic decimal parsing.
  - `"input-money"`: Currency editor with real-time numeric entry and automatic locale currency formatting.
- **Custom Web Component Editors**: Seamless cell binding to custom interactive widgets (`<status-selector>`, `<rating-editor>`, `<priority-badge-editor>`).
- Reactive event streams (`cell-change`) emitting updated cell coordinates, old values, and new values.

### 4. 🌐 Locale-Aware Number & Currency Formatting (`locale`)
- Built-in `locale` attribute for Jakarta Faces `<dh:dhGrid locale="en-US">` and Web Component `<dh-grid-element locale="...">`.
- Native integration with JavaScript `Intl.NumberFormat` to format raw numbers and money based on target country locales:
  - `en-US`: `$120,000.00`
  - `tr-TR`: `₺120.000,00`
  - `de-DE`: `120.000,00 €`
  - `ja-JP`: `￥120,000`

### 5. 🔒 Granular ReadOnly Control & Matrix Locking
- **Global ReadOnly Mode**: Lock all matrix cells grid-wide via `readOnly="true"` or `readonly="true"`.
- **Per-Cell & Per-Column Rule Maps**: Targeted editability rules via JSON or Java Map: `readOnlyCells='{"r1_c0": true, "c0": true}'`.
- **Visual Feedback & Animation**: Non-editable cell styling (`.grid-cell-readonly`) and distinct lock-shake feedback animation on invalid double-click or `Enter` edit attempts.

### 6. 🎨 Dynamic Cell Styling Strategy (`cellStyles`)
- Apply custom background colors, text colors, font weights, and font sizes per cell, row, or column:
  - `cellStyles='{"r1_c3": "background-color: rgba(34, 197, 94, 0.15); color: #4ade80; font-weight: 700;"}'`
- Supports both inline CSS rule strings and shorthand JSON objects (`{ "bg": "#1e3a8a", "color": "#60a5fa" }`).

### 7. ⌨️ Keyboard Navigation & Accessibility System
- **Arrow Keys (`Up` / `Down` / `Left` / `Right`)**: Move cell focus smoothly across rows and columns without triggering page scroll.
- **`Tab` / `Shift + Tab`**: Navigate cell by cell with automatic row wrapping. Commits active cell edits when editing.
- **`Enter`**: Launches cell editor or commits edit and moves focus down to the cell below.
- **`Escape`**: Cancels active edit without saving changes and restores target cell focus.
- **Accessibility & Focus Management**: Data cells feature native `tabindex="0"`, focus rings (`.grid-cell-focused`), and automatic `scrollIntoView` for large matrix scrolling.

### 8. 🎨 PrimeFaces Theme Compatibility (`css-compatible="primethemes"`)
- Set `css-compatible="primethemes"` on `<dh-grid-element>` or `cssCompatible="primethemes"` on `<dh:dhGrid>`.
- Internal Shadow DOM custom properties (`--dh-table-bg`, `--dh-header-bg`, `--dh-border-color`, `--dh-cell-color`, `--dh-focus-ring`) automatically map to active host PrimeFaces / PrimeVue CSS variables (`--surface-a`, `--surface-b`, `--surface-border`, `--text-color`, `--primary-color`).
- Adapts dynamically to themes such as `saga-blue`, `arya-dark`, `vela-blue`, `luna-amber`, `nova`, and `primeflex`.

### 9. 💾 Jakarta Faces Form Save & Real-Time Model Sync
- **Native `UIInput` Integration**: `DhGridComponent` inherits from `jakarta.faces.component.UIInput`, participating in JSF form decode, validation, and model update phases.
- **Zero-Dependency Matrix Parser**: Built-in string parser decodes submitted matrix payload into Java `String[][]` arrays without requiring external dependencies (Jackson/Gson).
- **Backend Action Support**: Save grid modifications directly with standard JSF buttons (`<h:commandButton action="#{gridBean.saveGrid}">`).
- **Global Client State**: Maintains `window.dhGridData` and syncs real-time cell edits to hidden form inputs (`#clientId_input`).

### 10. 🚀 GitHub Pages Maven Repository & Documentation
- Hosted public Maven repository on GitHub Pages (`https://dadhawk-dev.github.io/dh-grid/maven-repo/`).
- Interactive Live Showcase featuring a live **PrimeThemes Theme Switcher**, **2-Card JSF Code Viewer** (JSF View + CDI Bean), and live example preview modal (`▶ RUN Live Example`).

## 📦 Maven Dependency & Quick Start

### 1. Add GitHub Maven Repository & Dependency to `pom.xml`:

```xml
<repositories>
    <repository>
        <id>dadhawk-dhgrid-repo</id>
        <url>https://dadhawk-dev.github.io/dh-grid/maven-repo/</url>
    </repository>
</repositories>

<dependency>
    <groupId>com.dadhawk.faces</groupId>
    <artifactId>dhgrid-component</artifactId>
    <version>1.0.0</version>
</dependency>
```

### 2. JSF View Usage (`index.xhtml`):

```xml
<html xmlns="http://www.w3.org/1999/xhtml"
      xmlns:h="http://xmlns.jcp.org/jsf/html"
      xmlns:dh="http://dadhawk.com/faces">

<h:form id="gridForm">
    <dh:dhGrid id="myGrid"
               columns="#{gridBean.columns}"
               content="#{gridBean.content}"
               componentMap="#{gridBean.componentMap}"
               readOnly="#{gridBean.readOnly}"
               locale="en-US"
               cssCompatible="primethemes" />

    <h:commandButton value="Save Grid" action="#{gridBean.saveGrid}" />
</h:form>
</html>
```
