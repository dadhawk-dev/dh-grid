## 🌟 Overview

**Dadhawk DhGrid Component v1.0.1-alpha** is an update release for the Dadhawk DhGrid Web Component and Jakarta Faces library, addressing dynamic grid dimension constraints and header parsing.

---

## 🐛 Bug Fixes & Enhancements

### 1. 📐 Dynamic Matrix Dimension Calculation (`rows` / `cols`)
- **Fixed Hardcoded Minimum Dimension Constraint**: Fixed issue where `get rows()` and `get cols()` getters in `dh-grid.js` enforced a hardcoded minimum count of 5 columns and 5 rows (`Math.max(..., 5)`). This caused extra fallback columns (such as `Col 3`, `Col 4`, `Col 5`) to be automatically generated when setting `colCount="2"` or supplying small matrices.
- **Respect Explicit Attributes**: `get rows()` and `get cols()` now prioritize explicitly declared component attributes (`rows` / `cols`) and actual payload matrix dimensions before falling back to default dimensions.
